# 2025 美国大学生数学建模竞赛（ICM）Problem D

**获奖情况：Meritorious Winner（M 奖）**

**论文题目：** *Links among Individuals: An Optimized Higher-order Transportation Network Model*

## 项目简介

本项目针对 2025 年美国大学生数学建模竞赛（ICM）D 题，以美国巴尔的摩市交通网络为研究对象，围绕 Francis Scott Key Bridge 坍塌事件，研究关键交通基础设施失效对城市交通网络及不同群体的影响，并提出公共交通网络优化方案。

## 实现思路

### 1. 交通网络构建

首先对道路地理信息和交通流量数据进行清洗、整合与关联，利用道路节点和连接关系构建有向加权图，并引入年平均日交通流量（AADT）作为边权重。

在此基础上，引入**高阶网络模型（Higher-Order Network，HON）**，通过考虑交通路径的历史依赖关系，避免传统二元网络产生实际不存在的连接路径，使网络结构更贴近真实交通流动。

### 2. 级联失效模拟

建立**级联失效模型（Cascading Failure Model）**，根据节点度数定义初始负载，并通过容量系数确定节点的承载能力。

当关键节点因桥梁坍塌而失效时，将其负载按照相邻边权重和节点重要性重新分配。如果相邻节点承受的负载超过容量，则继续触发节点失效与负载重分配，直至网络达到稳定状态。

通过这一过程，分析局部交通设施失效如何在复杂交通网络中传播。

### 3. 关键节点识别与重要性评价

综合考虑节点度数、介数中心性、节点吸引率和节点转移率等网络特征，建立多维节点重要性评价体系。

采用**熵权法（Entropy Weight Method）**确定评价指标权重，再利用 **TOPSIS** 计算节点综合重要性得分并进行排序。

根据重要性得分将交通网络划分为核心层、桥接层和外围层，并从不同利益相关者视角分析桥梁坍塌的影响。

### 4. 公共交通网络分析与优化

以巴尔的摩公交站点及线路连接关系构建公共交通网络，分析城市中心与郊区的交通连接特征。

利用 **Gephi 的模块度优化社区发现算法**识别网络中的社区结构，分析不同区域之间的连通性及关键交通线路。

在此基础上，提出整合城市中心重复公交线路、增加跨区域快速公交线路、优化交通枢纽等改进方案，以增强交通网络的连通性与韧性。

## 技术方法

- 图论与复杂网络分析
- 高阶网络建模（HON）
- 级联失效模型（Cascading Failure Model）
- 熵权法与 TOPSIS 综合评价
- 社区发现与模块度优化
- MATLAB、Gephi
